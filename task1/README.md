# Transaction Report CLI

## Stage 1 - Run with a local JSON file

From the `task1` folder, run:

```bash
node transaction-report.js --file sample-transactions.json
```

## Stage 2 - Run with an HTTP(S) URL

From the `task1` folder, run:

```bash
node transaction-report.js https://raw.githubusercontent.com/baotrancuriopal/intern/main/task1/sample-transactions.json
```
