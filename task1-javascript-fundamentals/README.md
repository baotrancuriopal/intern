# Transaction Report CLI

## Stage 1 - Run with a local JSON file

From the `task1-javascript-fundamentals` folder, run:

```bash
node transaction-report.js --file sample-transactions.json
```

## Stage 2 - Run with an HTTP(S) URL

From the `task1-javascript-fundamentals` folder, run:

```bash
node transaction-report.js https://raw.githubusercontent.com/Baotran1404/intern-onsite/main/task1-javascript-fundamentals/sample-transactions.json
```
